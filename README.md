I'm a researcher and builder from Hyderabad. I like finding out what models really do, and making them fit on hardware people can afford.

<img align="left" width="280" hspace="12" alt="A programming quote, different on every visit" src="https://quotes-github-readme.vercel.app/api?type=vertical&amp;backgroundColor=07122e&amp;quoteColor=e6e8f5&amp;authorColor=c376ae&amp;symbolColor=e924ef"/>

**Now:** Research Intern on WISER, an Indo-German drone project for spotting pests in paddy. My part is multimodal data and sensor fusion.

**Also:** checking whether a sepsis model's explanations predict what it does, with Prof. Hamdi Al-Jamimi at KFUPM.

**Building:** [Vak](https://mudassiruddin7.github.io/#-ventures), AI literacy tools in Telugu and Hindi.

**Open to:** working together on interpretability, edge ML and model verification.

**Lately:** fixing bugs in TransformerLens, nnsight, Flower, Hugging Face datasets, skpro, movement and BrainGlobe. Small [pull requests](https://github.com/search?q=author%3AMudassiruddin7+is%3Apr&type=pullrequests), each with tests.

**Next:** Google Summer of Code 2027, starting with skpro.

<br clear="left"/>

### What I work on

- **Interpretability:** pulling the small circuit behind one behaviour out of a language model. [HAGD](https://github.com/Mudassiruddin7/HAGD) ships with a public audit of what its code reproduces.
- **Edge ML:** ResNet-18 pruned from 11.2M to 2.5M parameters, 142 ms per image on a Raspberry Pi 4. [PMP-DACIS](https://github.com/Mudassiruddin7/PMP-DACIS)
- **Efficient LLM agents:** each step runs at FP16, INT8, INT4 or INT2. The paper reports 68.3% less compute. [AgentCompress](https://github.com/Mudassiruddin7/AgentCompress)
- **Checking claims:** four detector upgrades that each helped alone but hurt together. [LAF-YOLOv10](https://github.com/Mudassiruddin7/Small-Object-Detection-in-UAV-Imagery)
- **Tools:** [LaTeX Intelligence](https://marketplace.visualstudio.com/items?itemName=MudassirUddinMohammed.latex-intelligence) turns LaTeX into an editable Word file. [Guardian-AI](https://github.com/Mudassiruddin7/Guardian-AI) filters prompt injections out of security logs.
